A quick overview of the main rules for using ReferredBy profiles and loan-related functions.

Using ReferredBy means managing a digital profile and accessing the functions available to that specific account, subject to the latest terms, digital contracts and product rules.

General use

  • The ReferredBy app is used to manage a digital profile and access available loan-related functions.
  • The latest terms, digital contracts and applicable product rules apply when the app is used.

  • Users must review the displayed terms before submitting a request.

Security

  • The app should be used only on supported devices, and users should log out when finished.
